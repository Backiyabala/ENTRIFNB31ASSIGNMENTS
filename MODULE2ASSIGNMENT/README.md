# Sign-Up Form

## Description

This is a simple Sign-Up Form created using **HTML, CSS, Bootstrap, and JavaScript**.

The form validates the user details before submitting the form.

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Features

* Full Name validation
* Email validation
* Password validation
* Confirm Password validation
* Terms and Conditions validation
* Responsive design
* Success message after valid submission

## Project Structure

Sign-Up-Form/
 index.html
 css/style.css
 js/validation.js

## How to Run

1. Open the project folder.
2. Open "index.html" in a web browser.
3. Enter the required details.
4. Click the **Sign Up** button.
5. The form will show validation messages for invalid inputs.

## Purpose

This project is created to practice **HTML forms, CSS styling, Bootstrap, JavaScript, Regular Expressions, and form validation**.
